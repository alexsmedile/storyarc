# storyarc

Turns any rough idea into a beat-by-beat script or carousel with open loops.

## Install

### Any Agent Skills host (`npx skills`)
```bash
npx skills add alexsmedile/storyarc
```

### Claude Code Plugin
```bash
/plugin marketplace add alexsmedile/storyarc
/plugin install storyarc@storyarc
```

### Portable Agent Plugin
Conforms to the [Agent Plugins](https://agent-plugins.org) standard (`plugin.json` + `skills/storyarc/SKILL.md`) for Claude Code, Codex, Cursor, Antigravity, and VS Code.

## Usage
Invoke `/storyarc` or ask your agent directly — see [`skills/storyarc/SKILL.md`](skills/storyarc/SKILL.md).
