# Story structure

Pick the structure that fits the topic, say which one in one line, then write.

A) Problem → what didn't work → the fix → the result → the takeaway
B) Before → turning point → after → how you can do it too
C) Myth → why people believe it → the truth with proof → what to do instead
D) List with an open loop: promise N items, keep the best one for last

Rules:
- Open a loop in the first 3 seconds and close it at the end.
- Every line has to earn the next one. Ask "so what?" after each line.
- One specific detail per beat: a number, a name, a moment.
- End with one clear action.

Output: the structure, the script with each beat labelled, and one line on why it holds attention.
